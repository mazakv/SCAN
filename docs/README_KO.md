# SCAN Rainbow Defense Toolkit v20 — 한국어 설명서

## 1. 개요
SCAN은 Windows 우선·로컬 우선의 방어적 점검 도구 모음입니다. 보안 상태를 확인하고, 사용자가 지정한 로컬 파일·프로젝트·패킷 캡처를 분석하며, 결과를 로컬 보고서로 저장합니다. SCAN은 전문 보안 제품을 대체하지 않으며 결과가 완전한 안전성을 보증하지 않습니다.

## 2. 시작하기
1. ZIP을 일반 폴더에 압축 해제합니다.
2. `SCAN.bat`를 실행합니다.
3. 동의 창에서 안내와 아래에 포함된 오픈소스 라이선스 전문을 스크롤하여 읽습니다.
4. 동의하는 경우 확인란을 체크하고 `AGREE / 동의`를 누릅니다. 동의하지 않으면 `거부 / 종료`를 선택합니다.
5. 선택 앱 화면에서는 필요한 도구만 고릅니다. `I`는 WinGet 설치, `D`는 다운로드만, `Q`는 취소입니다. 다운로드만 한 도구는 설치된 것으로 취급되지 않습니다.
6. 메인 메뉴에서 번호를 입력합니다. `p`는 이전 페이지, `d`는 다음 페이지, `r`은 도구 상태 새로고침, `0`은 종료입니다.

## 3. 메뉴 구성
내장 메뉴 60개와 선택형 외부 앱 16개가 있습니다. 세트는 일반 단일 기능과 구분된 `WORKFLOW SETS` 구역에 표시됩니다.
- 1: 자동 웹사이트 메타데이터 점검 세트. 공개 DNS/TLS/HTTP/RDAP 메타데이터 위주이며, 로그인·크롤링·폼 제출·익스플로잇·브루트포스를 하지 않습니다.
- 2: 승인된 단일 로컬/개인 IPv4 호스트에 대한 제한된 Nmap 검사.
- 35: Git/Gitleaks/Trivy 기반 프로젝트 보안 점검. 비밀값은 보고서에서 가리도록 설계되었지만 보고서를 공개하기 전에 직접 검토하세요.
- 36: 로컬 파일의 정적 검사, ClamAV/Sigcheck/7-Zip이 설치되어 있을 때 통합합니다. 파일을 실행하거나 압축을 풀지 않습니다.
- 37: cURL/OpenSSL 기반 HTTPS/TLS 교차 확인. 리디렉션을 따라가지 않도록 설계되었습니다.
- 38: Git 저장소 준비 상태 확인. 자동 커밋/푸시를 하지 않습니다.
- 39: Autoruns 시작 항목을 읽기 전용으로 보고합니다.
- 40: 로컬에 이미 존재하는 Docker 이미지의 점검. 자동으로 이미지를 내려받지 않습니다.
- 41: Python AST, Ruff, Node 구문 검사. 검사 대상 코드를 실행하지 않습니다.
- 43: 디스크에 있는 PCAP/PCAPNG 파일을 TShark로 요약합니다. 라이브 캡처를 시작하지 않습니다.
- 44: Windows OS/방화벽/Defender 정보 읽기 전용 요약.
- 45: 로컬 프로젝트의 CycloneDX SBOM 생성. SBOM은 취약점 판정이 아닙니다.
- 세트 A(46): Windows 기준선: OS, Defender, 방화벽, 수신 대기 포트의 읽기 전용 스냅샷.
- 세트 B(47): 프로젝트 릴리스 준비: Python 문법, Git 상태, 선택적으로 Gitleaks.
- 세트 C(48): 파일 트리아지: 정적 파일 정보와 SHA-256, 선택적으로 ClamAV.
- 49–60: 중복 파일 해시 비교, 대용량 파일 목록, JSON/XML/CSV 검사, 엔트로피 참고 지표, PEM 인증서 확인, Windows 이벤트 요약, 예약 작업 목록, 비밀정보로 오해될 수 있는 파일명 점검, IPv4 서브넷 계산, SCAN 로그 분석.

## 4. 개인정보와 데이터 흐름
- 기본적으로 로컬 파일 분석은 선택한 파일을 컴퓨터에서 읽습니다. 기능에 따라 외부 CLI 도구가 실행될 수 있습니다.
- 웹 메타데이터 메뉴를 실행하면 입력한 도메인/호스트가 DNS, RDAP, TLS 또는 HTTP 요청에 사용될 수 있습니다.
- 로그와 보고서에는 파일 경로, 사용자 이름, 도메인, IP 주소, 프로젝트 이름, 소프트웨어 목록 또는 패킷 메타데이터가 포함될 수 있습니다.
- SCAN은 보고서를 자동으로 공개하거나 GitHub에 자동으로 업로드하지 않습니다.
- `Logs` 폴더를 공개 저장소에 올리지 마세요. 보고서를 공유하기 전에 민감한 내용을 직접 확인하고 제거하세요.
- 동의 창에서 거부하거나 창을 닫으면 초기 작업이 종료됩니다.

## 5. 안전한 사용 범위
- 검사 대상 시스템의 소유자이거나 명시적 허가를 받은 경우에만 사용합니다.
- 자동 웹사이트 세트는 침투 테스트가 아닙니다. 로그인 시도, 크롤링, 폼 제출, 브루트포스, 익스플로잇, 리디렉션 추적을 수행하지 않습니다.
- Nmap은 SCAN에서 허용하는 단일 로컬/개인 IPv4 대상에 한정됩니다.
- SQLMap은 `localhost`, `127.0.0.1`, `::1`의 본인 로컬 실습 앱에만 사용합니다. 공개 웹사이트나 타인의 시스템에 사용하지 마세요.
- 파일 분석은 참고 자료이며, 엔트로피·파일명·해시만으로 악성 여부를 확정할 수 없습니다.
- 도구가 없으면 SCAN은 해당 기능을 건너뛰거나 설치 필요를 알립니다. 작업 중 몰래 설치하지 않습니다.

## 6. 보고서와 로그 관리
실행 중 로그는 `Logs`에 생성되며 보고서는 `Logs/reports`에 저장될 수 있습니다. 릴리스 ZIP에는 불필요한 과거 로그/챌린지 로그/이전 변경 기록을 포함하지 않습니다. 로그는 실행 시 다시 만들어집니다. 로그와 보고서는 진단에 도움이 되지만 개인·조직 정보를 포함할 수 있으므로 공개하지 마세요.

## 7. 문제 해결
- PowerShell 실행/정책 오류: ZIP을 완전히 압축 해제한 뒤 `SCAN.bat`를 실행하고 파일이 차단되었는지 확인합니다. 보안 설정을 무리하게 비활성화하지 마세요.
- 도구 없음: 메인 메뉴의 도구 상태/설치 센터를 확인하고 공식 배포처에서만 설치합니다.
- 결과가 비어 있음: 대상 경로가 맞는지, 권한과 도구 설치 상태를 확인합니다.
- SQLMap 진단: 시간 초과는 그 자체로 소스가 손상되었다는 뜻이 아닙니다. 로컬 실습 환경만 사용하세요.
- Windows에서 실행 확인이 필요한 기능은 Windows 환경에서 직접 시험해야 합니다. 다른 OS에서 정적 검사/단위 테스트가 통과해도 Windows Forms/WinGet이 검증된 것은 아닙니다.

## 9. 프로젝트 구조
- `SCAN.bat`: Windows 진입점
- `consent.ps1`: 개인정보/안전/라이선스 동의 창
- `bootstrap.ps1`: 초기 설정 및 선택 도구 처리
- `scan.py`: 메인 메뉴와 워크플로 로직
- `site_audit.py`, `security_audit.py`, `security_analysis.py`: 보조 점검 모듈
- `tests/`: 로컬 단위 및 무결성 테스트
- `LICENSE`, `LICENSES/`: 프로젝트/외부 라이선스 자료
- `docs/`: 다국어 설명서
