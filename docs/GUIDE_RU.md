# SCAN Rainbow Defense Toolkit v20 — Руководство на русском языке

## Обзор
SCAN — набор защитных инструментов для проверки, ориентированный на Windows и локальную обработку данных. Он помогает проверять состояние компьютера, выбранные локальные файлы, исходные проекты, сохранённые сетевые дампы и наличие утилит, сохраняя отчёты локально. Чистый результат не доказывает абсолютную безопасность системы.

## Быстрый запуск
1. Распакуйте ZIP в обычную папку.
2. Запустите `SCAN.bat`.
3. Прокрутите окно согласия, включая полный текст встроенных лицензий в конце.
4. Если согласны, отметьте флажок и нажмите `AGREE / 동의`; иначе нажмите `거부 / 종료`.
5. Выберите только необходимые дополнительные приложения. `I` устанавливает через WinGet, `D` только скачивает, `Q` отменяет. Одно скачивание не означает установку.
6. Введите номер меню: `p` — назад, `d` — вперёд, `r` — обновить состояние утилит, `0` — выход.

## Меню и наборы сценариев
Есть 60 встроенных действий и 16 дополнительных приложений. Наборы рабочих процессов отображаются отдельно от одиночных утилит.
- 1: только чтение публичных метаданных DNS/TLS/HTTP/RDAP; без входа, обхода сайтов, отправки форм, эксплуатации, перебора паролей и переходов по перенаправлениям.
- 2: ограниченная проверка Nmap одного разрешённого локального/частного IPv4-узла.
- 35: аудит проекта с Git, Gitleaks и Trivy; перед публикацией отчёт следует проверить вручную.
- 36: статическая проверка локальных файлов; файлы не запускаются и архивы не распаковываются.
- 37: проверка HTTPS/TLS с cURL/OpenSSL.
- 38: проверка состояния Git-репозитория; автоматических commit/push нет.
- 39: просмотр Autoruns только для чтения.
- 40: проверка уже локально имеющегося Docker-образа без автоматической загрузки.
- 41: проверки Python AST, Ruff и синтаксиса Node; код проекта не выполняется.
- 43: сводка сохранённого PCAP/PCAPNG через TShark; живой захват не запускается.
- 44: сводка Windows, брандмауэра и Defender только для чтения.
- 45: создание CycloneDX SBOM; SBOM не является заключением об уязвимостях.
- Набор A (46): базовое состояние Windows.
- Набор B (47): готовность проекта к выпуску.
- Набор C (48): статический анализ файлов.
- 49–60: поиск дубликатов по хешу, большие файлы, проверка JSON/XML/CSV, оценка энтропии, PEM-сертификаты, сводка событий Windows, запланированные задачи, подозрительные имена файлов, калькулятор IPv4-подсетей и анализ журналов SCAN.

## Конфиденциальность и безопасность
Функции веб-метаданных могут отправлять введённое имя хоста службам DNS, RDAP, TLS или HTTP. Журналы и отчёты могут содержать имена пользователей, локальные пути, домены, IP-адреса, имена проектов, сведения о ПО или метаданные пакетов. Не публикуйте `Logs` и отчёты в открытом репозитории. Проверяйте только собственные системы или системы с явным разрешением. SQLMap ограничен локальным учебным приложением, запущенным вами на `localhost`, `127.0.0.1` или `::1`.

## Журналы и устранение неполадок
Журналы создаются заново при запуске. Для уменьшения размера в ZIP не включены старые журналы, журналы испытаний и устаревшие файлы истории изменений. Окно Windows Forms и WinGet нужно проверять непосредственно в Windows.
