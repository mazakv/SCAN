# SCAN Rainbow Defense Toolkit v20 — 日本語ガイド

## 概要
SCAN は Windows を優先し、可能な限りローカルで動作する防御目的の調査ツール集です。PC の状態、指定したローカルファイル、ソースコード、パケットキャプチャ、ツールの導入状況を確認し、レポートをローカルに保存します。結果が正常でも安全性を完全に保証するものではありません。

## 起動方法
1. ZIP を通常のフォルダーに展開します。
2. `SCAN.bat` を実行します。
3. 同意画面をスクロールし、末尾にあるオープンソースライセンス本文も確認します。
4. 同意する場合はチェックボックスを選択して `AGREE / 동의` を押します。同意しない場合は `거부 / 종료` を選択します。
5. 必要な追加アプリだけを選びます。`I` は WinGet によるインストール、`D` はダウンロードのみ、`Q` はキャンセルです。ダウンロードだけではインストール済みになりません。
6. メニュー番号を入力します。`p` は前ページ、`d` は次ページ、`r` は状態更新、`0` は終了です。

## セットと機能
内蔵機能は 60 項目、任意アプリは 16 個です。ワークフローセットは単独機能とは別のセクションに表示されます。
- 1: 公開 DNS/TLS/HTTP/RDAP 情報を読むウェブサイトメタデータセット。ログイン、クロール、フォーム送信、攻撃、総当たり、リダイレクト追跡は行いません。
- 2: 許可された単一のローカル/プライベート IPv4 ホストへの制限付き Nmap 検査。
- 35: Git/Gitleaks/Trivy によるプロジェクト検査。共有前にレポートを確認してください。
- 36: ローカルファイルの静的検査。ファイルを実行・展開しません。
- 37: cURL/OpenSSL による HTTPS/TLS 照合。
- 38: Git リポジトリの状態確認。自動コミット/プッシュは行いません。
- 39: Autoruns の読み取り専用確認。
- 40: ローカルに存在する Docker イメージの検査。自動取得しません。
- 41: Python AST、Ruff、Node の構文確認。対象コードを実行しません。
- 43: 保存済み PCAP/PCAPNG の TShark 要約。ライブキャプチャは開始しません。
- 44: Windows、ファイアウォール、Defender の読み取り専用概要。
- 45: CycloneDX SBOM の生成。SBOM は脆弱性判定ではありません。
- セット A (46): Windows 基準情報。
- セット B (47): プロジェクト公開準備。
- セット C (48): ファイルの静的トリアージ。
- 49–60: 重複ハッシュ、大容量ファイル、JSON/XML/CSV 検証、エントロピー参考値、PEM 証明書、イベントログ、タスク一覧、機密情報らしいファイル名、IPv4 サブネット、SCAN ログ分析。

## プライバシーと安全
ウェブメタデータ機能では入力したホスト名が DNS/RDAP/TLS/HTTP サービスに送信される場合があります。ログやレポートにはユーザー名、ローカルパス、ドメイン、IP、プロジェクト名、ソフトウェア情報、パケットメタデータが含まれる可能性があります。`Logs` とレポートを公開リポジトリへ登録しないでください。所有するシステム、または明示的な許可を得たシステムだけを検査してください。SQLMap は `localhost`、`127.0.0.1`、`::1` 上の自分で起動したローカル練習アプリに限定してください。

## ログとトラブルシューティング
ログは実行時に `Logs` に再作成されます。リリース ZIP から古いログ、チャレンジログ、古い変更履歴を削除して軽量化しました。Windows 固有の画面や WinGet は Windows 上で確認する必要があります。
