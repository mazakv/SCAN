# SCAN Rainbow Defense Toolkit v20 — 中文指南

## 概述
SCAN 是面向 Windows、尽量在本地运行的防御性检查工具集。它可以检查主机状态、用户选择的本地文件、源代码项目、数据包捕获文件和工具可用性，并将报告保存在本地。检查结果正常并不代表系统绝对安全。

## 快速开始
1. 将 ZIP 解压到普通文件夹。
2. 运行 `SCAN.bat`。
3. 在同意窗口中滚动阅读隐私、安全说明以及末尾的开源许可证全文。
4. 同意后勾选确认框并点击 `AGREE / 동의`；不同意则点击 `거부 / 종료`。
5. 只选择需要的可选应用。`I` 表示通过 WinGet 安装，`D` 表示仅下载，`Q` 表示取消。仅下载不等于已安装。
6. 输入菜单编号。`p` 上一页，`d` 下一页，`r` 刷新工具状态，`0` 退出。

## 菜单与工作流套件
共有 60 个内置操作和 16 个可选应用。工作流套件会与单项工具分开显示。
- 1：只读网站元数据检查，涉及公开 DNS/TLS/HTTP/RDAP 信息；不登录、不爬取、不提交表单、不利用漏洞、不暴力破解，也不跟随重定向。
- 2：对单个、获准的本地/私有 IPv4 主机进行有限 Nmap 检查。
- 35：使用 Git、Gitleaks、Trivy 检查项目；分享报告前请人工复核。
- 36：本地文件静态检查；不会执行文件或解压归档。
- 37：使用 cURL/OpenSSL 交叉检查 HTTPS/TLS。
- 38：检查 Git 仓库状态；不会自动提交或推送。
- 39：只读检查 Autoruns。
- 40：检查已经存在于本机的 Docker 镜像，不会自动拉取镜像。
- 41：Python AST、Ruff、Node 语法检查；不会执行被检查的项目代码。
- 43：使用 TShark 汇总本地 PCAP/PCAPNG 文件，不启动实时捕获。
- 44：只读汇总 Windows、Firewall 和 Defender 状态。
- 45：生成 CycloneDX SBOM；SBOM 不是漏洞结论。
- 套件 A（46）：Windows 基线。
- 套件 B（47）：项目发布准备。
- 套件 C（48）：文件静态分诊。
- 49–60：重复文件哈希、大文件清单、JSON/XML/CSV 校验、熵值参考、PEM 证书、Windows 事件摘要、计划任务清单、疑似秘密文件名检查、IPv4 子网计算和 SCAN 日志分析。

## 隐私与安全边界
网站元数据功能可能将输入的主机名发送到 DNS、RDAP、TLS 或 HTTP 服务。日志和报告可能包含用户名、本地路径、域名、IP 地址、项目名称、软件信息或数据包元数据。不要把 `Logs` 或报告提交到公开仓库。仅检查自己拥有或明确获准检查的系统。SQLMap 仅限 `localhost`、`127.0.0.1`、`::1` 上由你自己启动的本地练习应用。

## 日志与故障排查
运行时日志会在 `Logs` 中重新创建。为减小体积，发布包不包含旧日志、挑战日志和过时的变更记录。Windows Forms 与 WinGet 必须在 Windows 环境中验证。
